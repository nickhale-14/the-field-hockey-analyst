# Data scope and gotchas

Read this before writing any query or starting any analysis. Most of it is the difference between a number that is right and one that merely looks right.

Everything below is the England database (`hockey_stats`). **German 1. Bundesliga data is in a separate database, `hockey_stats_de`**, with its own coverage and gotchas: see [germany.md](germany.md).

- **4 historic seasons ingested**: 2022-23 through 2025-26 (full match data, England only — Men's + Women's, national leagues: Premier, Division 1 North/South, Conference North/West/East/Midlands, plus playoffs/finals)
- **3 earlier Prem seasons, scores only (2019/20, 2020/21, 2021/22, both genders — 443 matches)** transcribed from flashscore.com page text (`data/raw/flashscore/raw/*.txt`, loaded by `ingest import-flashscore`; parser in `data/ingest/src/ingest/sources/flashscore_text.py`). Prem only, no Division 1/Conference, no scorers/cards/players. Shape: 2019/20 = full 10-team double round-robin (90/gender; play-offs cancelled by COVID); 2020/21 = COVID stub, Sept–Oct only (26 M / 27 W); 2021/22 = 11-team single round-robin (55) + Phase 2 Top 6 (30) and "Lower 6" (actually 5 teams, 20). **No Finals Weekend / relegation play-offs for these seasons** (Flashscore didn't carry the 2022 finals). Status `W` = awarded walkover (one: Hampstead 5–0 Holcombe, 21 Feb 2022) — excluded by `status='R'` like everything else non-played. **Verified 2026-09-24 against England Hockey's own record** (`ingest verify-flashscore`): Altius holds both 2019/20 (comps 206 W / 207 M) and 2020/21 (246 M / 247 W), and all 233 of those matches now agree — every fixture present on both sides, one score corrected (2019/20 W Buckingham v Bowdon: Flashscore said 3-2, England Hockey's match page lists four goals ending 2-2; see `corrections.SCORE_CORRECTIONS`, applied by `ingest repair`). **2021/22 is not on Altius and remains unverified.** Note Altius is England Hockey's own platform, a different system rather than a different organisation — where it and Flashscore (an unaffiliated aggregator) disagree, England Hockey wins. Flashscore's terms forbid automated scraping, so these were read page-by-page in a browser and pasted, not fetched; the archive goes back to 2009/10 if more is ever wanted (older pages also carry half-time scores, which we don't store).
- **2026-27 (current season)**: full fixture list, scores as they come in, and **goals/cards/squads for played matches** (since 2026-09-22 — `import-fixtures` fetches `/fixtures/{id}` for every played match the DB has no events for, so a weekly run costs about one call per new result; a played match with zero events is retried each run because clubs log late). Last refreshed 2026-09-22: round 1 of Division 1 / Conference (19–20 Sept, 60 matches) has results and events; the Prem starts 26 Sept. **Weekly routine: now `./weekly.sh call` / `./weekly.sh verdict`** (2026-10-19), which does the ingest steps below for the Prem graphics. The older manual routine (in this order, the predictions file must predate the results): `predictor.py --upcoming` for both genders → `ingest import-fixtures` → `ingest backfill-events --season "2026/27"` (catches half-logged matches, see pipeline.md) → `ingest repair` → `analysis/score_weekend.py --from <sat> --to <sun> analysis/output/upcoming_{M,W}_to_2026-12-31.csv` (writes the card; save it under `analysis/reports/weekend_<date>.txt`) → `./data/seed/dump.sh` and commit. After a few rounds, re-run the nickname-duplicate scan (bug #6).
- **Event types**: `FG`/`PC`/`PS` are all **goals** (field goal / penalty-corner goal / penalty-stroke goal — NOT "PC awarded", confirmed by cross-checking event counts against final scores). `GC`/`YC`/`RC` are green/yellow/red cards.
- **Match status codes**: `R`=Result, `A`=Abandoned, `S`=Scheduled (live season only), `P`=Postponed (rare: one historic, plus Repton M1 v Leek 1, 7 Nov 2026, which stayed `S` for two days before England Hockey marked it `P`, so an `S` on Monday is not yet a gap), `W`=awarded walkover (Flashscore seasons only, 1 seen). **Always filter `WHERE status='R'`** for any goal/card/result analysis.
- **Known data gaps** (source-side, not our bug — confirmed against the live API):
  - **Coverage audit (re-run 2026-09-23, `status='R'`, all 26 competitions/season):** 2022/23 **8 of 1,316** matches have events; 2023/24 1,257 of 1,316 (96% of matches, **91% of goals**); 2024/25 1,313 of 1,316 (100%/100%); 2025/26 1,312 of 1,316 (100%/100%); 2026/27 60 of 60 so far.
  - **2026/27: Bowdon 2 3-1 Loughborough Students 2 (Women's Division 1 North, 10 Oct) has no scorers or cards upstream** (`backfill-events` reports "none upstream"; re-checked 9 and 11 Nov 2026). The only 2026/27 played match without events as of 11 Nov; every other one has one goal event per goal.
  - **2022-23**: effectively zero event/player data (the system didn't exist yet). The only 8 matches with events are the Altius Finals Weekend imports — every one of the 1,308 league matches is scores-only. Usable for results/Elo, never for goals/cards/PC analysis.
  - **2023-24**: 96% of matches have events but the gap is concentrated in the worst place — **Men's Premier: 21 of 118 matches with none, and only 75% of its goals have an event row.** Women's Prem 96%, Division 1 94-95%, Conference 91-92%. So men's Prem 2023/24 is NOT safe for goal-type/timing/scorer work; the other tiers are usable with care. **2024-25 onward is clean** (goal events equal the scoreline in every match) — start every event-based analysis at 2024/25 unless there's a reason not to.
- **Terminology**: "Men's/Women's Prem" (no qualifier) = regular season + League Finals Pool A/B + Phase 2 Top6/Lower6 — **excludes** Relegation Play Offs. "Prem Play Offs" = Relegation Play Offs specifically — named `…Play Offs Phase 3` in 2022/23 and 2023/24, `…Relegation Play Offs` from 2024/25 (same 4-team round robin; match both names). "Finals Weekend" = the end-of-season play-off semi-finals + 3rd/4th + play-off final (competition `…Premier Division Finals Weekend`, 4 matches per gender per season). **The stage is NOT stored** — all four share one competition name. Infer it from kick-off order and participants: two semis first, then the 3rd/4th between the two semi LOSERS, then the final between the two semi winners, last on the Sunday. (Got this wrong once, 2026-09-25: 4 May 2025 Old Georgians 1–2 Surbiton is the final — Surbiton were 2024/25 champions — not the 3rd/4th, which was Oxted 0–0 Wimbledon, SO 3–2, earlier that morning.) **In published content call these the "play-off semi-finals" and the "play-off final"** (user, 2026-09-25) — never "Grand Final", whatever the competition row is named. **And name the stages Phase 1 / Phase 2 / Phase 3, never "League"**: `…Premier Division` (the 66-match regular season) = Phase 1, `…Phase 2 Top 6/Lower 6` = Phase 2, `…Relegation Play Offs` (once `…Play Offs Phase 3`) = Phase 3. **Phase 3 is the whole April stage, not just the relegation strand**: the League Finals Pools (18–25 Apr 2026) and the Relegation Play Offs (18 Apr – 2 May) run in the same window, top half and bottom half of the same round. So **"Phases 1–3" = 114 matches per gender** — every Prem match on the 1–70 league clock, Finals Weekend (1–60 clock) excluded. 2025/26 cards on that scope: men's 280, women's 207. Only the Prem has play-offs/finals; Division 1 and Conference are league-only. **A complete Prem season 2022/23–2025/26 is 118 matches per gender**: 66 regular + 12 League Finals Pool + 30 Phase 2 + 6 relegation play-off + 4 Finals Weekend — verified for all four historic seasons.
- **Finishing position comes from the BRACKET, not the points total — never sort the combined table by points.** The Phase 1 standing decides who goes into Top 6 or Lower 6, and that assignment fixes the range: Top 6 finish 1–6, Lower 6 finish 7–12, whatever either group accumulates afterwards. **A bottom-six team finishing on more points than a top-six team is the norm, not an anomaly** (user, 2026-10-15): the side that scrapes 6th plays only the top half after Christmas while 7th plays only the bottom half, so 6th usually struggles. The numbers bear it out across all five bracket seasons — average points per game by finishing position runs 5th 1.52, **6th 0.85, 7th 1.45**, 8th 1.23, so **6th is the only rank that averages fewer points than the rank below it** (the single negative step in the table; `analysis/reports/prem_tiers_2026-09-23.txt`, section 2). 2025/26 men's is the sharpest case: Phase 1 separated **Oxted 13 points from East Grinstead 12, one point**, so Oxted went up and EG down. Phase 2 then ran the other way, Oxted taking **0 from 5** against the top half while EG took **11 from 5** against the bottom. Final totals Oxted 13, EG 23; final positions Oxted **6th**, EG **7th**. (Got this wrong on 2026-09-25: sorted the 16-game table by points and called Oxted 10th. No table had been published, so nothing needed correcting, but don't repeat it.) Also why the power rankings in [`modelling.md`](modelling.md) legitimately rate EG above Oxted while the official table does not: Elo rates performance, the table encodes the bracket. Say which you mean in published content.
- **Where each stage is played (user, 2026-10-20).** Phase 1, Phase 2 and the League Finals Pools are at the listed home side's own ground. **Relegation play-offs are at a neutral venue** (Surbiton may have hosted one year). Finals Weekend is one host venue (Surbiton, 2023/24 and 2025/26). The `venues` table often names the ground, not the club (Raynes Park High School, Paddington Recreation Ground, St George's College), so a string match on the club name undercounts home games. **The league breaks for internationals**: no league game is played while international squads are away, so call-ups never cost a side players.
- **New structure from 2026/27** (England Hockey graphic, user-supplied 2026-09-19): Matches 1–11 Sept–Nov, single round-robin (Phase 1) → points carried, split Top 6 / Lower 6, matches 12–16 Mar–Apr, play each other once (Phase 2) → **Finals for the top 8** (Top 6 + the two best of the Lower 6): **two-legged quarter-finals in April, home and away** (1st v 8th, 2nd v 7th, 3rd v 6th, 4th v 5th), then semis (W QF1 v W QF4, W QF2 v W QF3), final and 3rd/4th in May → **Relegation: 9th–12th**, points carried, play each other once in April, bottom two down. So **no more League Finals Pool A/B**; expect new competition names for the QFs (add them to `TARGET_COMPETITIONS` in both API importers when they appear — they will NOT match the current filter), Finals Weekend presumably still on Altius. Season = 66 + 30 + 8 QF legs + 4 finals + 6 relegation = 114 per gender. EuroHockey spots: finals winner, 1st in the Top 6 after match 16, then the 3rd/4th winner. Two-legged ties are aggregate — the predictor and the "stage" labels in `analysis/graphics/h2h_carousel.py` (which call the pools "Phase 3") will need updating for 2026/27.
- **Finals Weekend comes from a different source.** England Hockey runs it as a tournament on `englandhockey.altiusrt.com` (Altius RT), NOT in the league API — the API only ever had the 2023/2024 men's finals, no women's, and a ghost `TBC v TBC` row for 2025. `ingest import-finals` scrapes the 8 known Altius competitions (ids in `eh_altius.KNOWN_FINALS_COMPETITIONS` — add next season's when it runs) and the league importers now skip any API competition named "Finals Weekend" so nothing double-counts. All 32 finals matches 2023–2026 are in, with goals/cards/officials, and every match's goal events sum to its scoreline.
- **Shootouts**: `matches.home_shootout` / `away_shootout` (NULL for league games). The match score stays the drawn score (e.g. Oxted 0–0 Wimbledon, 3rd/4th 2025) so goal stats are right; the shootout columns say who went through. `WHERE home_shootout IS NOT NULL` finds them.
- **Event minutes are on two clocks.** League API `match_events.minute` runs **1–70** (the club scoring app's running clock — no stopped time at club level; histogram is continuous 1→70 with a half-time dip at 36, no 9-minute break gaps, so it's a 70-scale, NOT wall-clock-with-breaks). The Altius Finals Weekend events run **1–60** (technical table, clock stopped). No `period`/quarter field exists in either source. **Quarters are 17.5 minutes** (user, 2026-10-07), so on a 1–70 integer clock the quarter boundaries fall at 17.5 / 35 / 52.5 and **minutes 18 and 53 each straddle a break** — they cannot be assigned to one quarter. Split them half-and-half rather than bucketing 1–17 / 18–35 / 36–52 / 53–70, which silently gives Q2 and Q4 an extra minute and Q1/Q3 one fewer: that alone moved the 2025/26 Prem Q4 card share from 39% to 40% and the Q4÷Q1 ratio from 4.6× to 5.1×. **Halves (1–35 / 36–70) are exact and need no such fudge — prefer them for any headline claim.** **A PC goal on a boundary minute (18, 53) belongs to the earlier quarter:** a corner awarded as the quarter ends is played out after the hooter (user, 2026-11-13; it settled Reading's "highest final-quarter share" on Breakdown R9, where one of Exeter's two minute-53 goals was a PC). Field goals on those minutes stay split. The goal-rate dips at minutes 1, 19, 36 and 54 corroborate the four-segment structure. Finals (1–60 clock) quarters are a clean 15 each. A league "70'" is the last minute of Q4, not stoppage time. About 17% of league goals sit above 60 for this reason.
- **Card impact (done 2026-09-18, ad-hoc SQL, 2024/25+2025/26, all national leagues, 5,751 cards):** during a green (2 app-min window) the opposition scores at 1.31× the minute-matched expected rate and the carded team at 0.58×; during a yellow (6 app-min ≈ 5 real) 1.38× / 0.75×. Effect vanishes the minute the player returns (no tail after 5 min → 10-min yellows are rare). PC-goal share is ~40% inside and outside windows, so it's the numbers, not just the corner given with the card. Method: per card, sum league-wide per-minute goal rate over the window as "expected". **Confirmed properly 2026-09-25** (`analysis/card_impact.py`, report in `analysis/reports/card_impact_2026-09-25.txt`) by decomposing window goals by TYPE and by LAG after the card — the card->corner->goal worry. Baseline PC share 36%. Greens, team a man up: 649 goals, 40% PC, and the lag profile is FLAT (219/225/205 goals at +0/+1/+2 min; PC share 38/40/42%) — a corner-driven effect would spike at +0 and decay, so greens are genuinely about being 10 v 11. Yellows do front-load (118 goals at +0, 48% PC, decaying to ~30% by +3), so part of the yellow effect IS the accompanying corner. Sizing the confound by excess PC share over baseline: ~30-40 goals of 1,163 man-up window goals, about **3%**. Real, small, not the explanation. When the CARDED team scores short-handed its PC share drops to 30%, below baseline — counter-attacks.
- **Player identity**: `players.club_id` is whichever club the league API first showed the person with — it does **not** follow transfers (Nick Bandurak's Surbiton goals sit under a Holcombe-club player row). Never infer "who plays for whom" from `players.club_id`; use `match_events.team_id`. The finals importer resolves names by ranking "has events for this team" > "same club" > "unique name in the DB", lists its weaker decisions, and refuses six common-name/different-club cases (`eh_altius.NO_LINK`) which got fresh rows instead. Altius-created players have `source_id` like `altius:player:…` (16 of them, mostly 2022-23 finals players the API never had). Same person under two player ids → `PLAYER_ALIASES` in `aliases.py`, same mechanism as teams/clubs (loader rewrites on ingest, `ingest apply-aliases` merges existing rows); first entry is Altius's mangled "DREW Victoria" → Victoria Drews (H&W).
- **Player appearances**: squad list available (~16/team/match), but the `played` flag is never populated by the source — can't distinguish "started" from "was in the squad." Starting lineups were explicitly deprioritized anyway (rolling subs). **Coverage (probed 2026-10-17, 40 sample Prem fixtures): squads start in 2023/24.** 2022/23 has none (like its events); 2023/24 onward has a full 16-a-side list in every phase sampled, including a 2023/24 match whose events are missing, so squads may be more complete than events that season. Each entry has `memberId` (all present, even the rare no-consent player), `shirtNumber`, and `otherRoleDescription` GK / CAPT; `started` and `played` are always 0. Finals Weekend isn't in the API (404); Altius pages carry lineups (`eh_altius.LineupEntry`). **Stored since 2026-10-17 in `match_players`** (one row per squad place: match, team, player, shirt number, GK/captain flags; a player without consent gets a row with `player_id` NULL and no member id). `import-fixtures` records squads for new matches automatically; `ingest backfill-squads --season <name> [--competition 'Premier Division']` fills older ones. Finals Weekend squads (Altius lineups) are not loaded. **Backfilled so far: every Prem match 2023/24-2026/27** (212/228, 228/228, 228/228, 35/35; the 16 missing in 2023/24 have nothing upstream, and 9 of its Phase 2 squads are partial lists of 1-10) plus 100 lower-tier 2023/24 matches. The rest of Division 1/Conference is NOT backfilled: Prem first, by the user's call (2026-10-17), and the backfill now pauses 1s between calls so it doesn't hammer the API. In the Prem, 19 of 4,688 named goals/cards (0.4%) are by a player not in that day's squad. **Unnamed squad places** (no consent, `player_id` NULL) in the 2025/26 Prem: Holcombe M1 #1 GK (17 incl. finals pool), Barnes W1 #6 (6), Clifton Robinsons W1 #7 (7), plus one each for H&W W1 and Reading M1; none so far in 2026/27. The first two are named from the clubs' own team sheets via `corrections.SQUAD_IDENTITIES` (Dom Dixon, Liv Buchanan; source `manual`), applied by `ingest repair`. Clifton's #7 is left unnamed on purpose: the club's own lineup graphics omit her too. Each team's unnamed places always share one shirt number, so count them as one player.
- **Corners awarded are not recorded — only corners scored.** `PC` is a penalty-corner *goal*; there is no event for winning one. So any question of the form "does X change how many corners a team wins" is unanswerable, and the card→corner→goal test above could only be run on goals. Pairs with bug #8 in [`pipeline.md`](pipeline.md): the event table is neither complete nor self-describing, so check what an event actually represents before building on it.
- **Split team-level averages by opponent tier before quoting them.** In a league with the Big 5 in it, a mid-table side's raw averages are mostly a record of being beaten by the top five, not of how it plays the teams it competes with, and the two pictures can be opposite. Oxted M1 over 2024/25+2025/26 read 3-4-12 conceding 5.08 a game overall, but **8-3-3 conceding 2.14** against non-Big-5 opposition — because 24 of their 38 matches were against the top five. Lower-half sides in the same seasons differ in how often they met the Big 5 (East Grinstead 15 of 38, Oxted 24 of 38), so even comparing two mid-table teams' raw numbers is unsafe. `analysis/scout.py` prints the split before every other section; do the same in any team-level analysis or content. (Its Big 5 list is hardcoded — keep it agreeing with the points-per-game definition in [`findings.md`](findings.md).)
- **Competition names drift between seasons**: sponsor prefixes come and go ("Vitality Women's Premier Division" 2022/23, "Open - Men's Premier Division" from 2025/26) and spelling varies ("Womens Premier Division" from 2023/24, no apostrophe). The same league is therefore several `competitions` rows with different names. Match loosely (strip prefixes, normalise apostrophes) — `mcp/server.py:_norm_comp` does this — and never `LIKE '%Men''s ...%'` (it also matches "Women's").
- **Team name gotcha**: 18 team names are shared by two genuinely different real teams (a club's Men's and Women's sides, when that club doesn't add a gender suffix like "M1"/"W1" to the name) — don't join/group by team name alone across genders. The 18 (each a distinct `source_id` per gender): Bedford 1, Beeston 2, Belper 1, Cambridge City 1, Chelmsford 1, Clifton Robinsons 1, Didsbury Northern 1, Durham University 2, Harleston Magpies 1, Ipswich 1, Marlow 1, Newcastle University 1, Oxford University 1, Stourport 1, Timperley 1, Trojans 1, University of Birmingham 2, University of Nottingham 2.
- **Club badges**: `clubs.logo_url` holds the crest URL (from `clubportal.englandhockey.co.uk`). 104 of 111 clubs have one; the 7 without simply never uploaded a crest to England Hockey (plus the "England Hockey - TBC" placeholder club). Both importers capture it going forward; `ingest backfill-club-logos` fills it via the API's `/clubs/{id}` endpoint (field is `logoUrl` there, `clubLogoUrl` on team objects inside fixtures). Local image files: `analysis/download_badges.py`. Badges are per **club**, so join `teams → clubs` to get one for a team (M1/M2/W1 all share the club's crest).
- **Promotion and relegation history comes from the tables, not a field.** Nothing stores who went up or down; a team's league each season is just which competition its matches are in. Below the Prem every league is a plain 10-team double round-robin (90 matches), so a finish is the points/GD/GF table of that one competition; a Prem finish uses the bracket rule above. A season with no national-league matches means the side was in a regional league that year (checked 2026-10-24 for Neston, Marlow M, Peterborough, Cambridge University W, Alderley Edge, Oxford University W: no second team id for the same club and gender, so it's a real gap, not an alias problem). Same-name sides (Marlow 1, Trojans 1, Clifton Robinsons 1...) need the gender of the competition or the team id, never the name. **Promotion is one up per league, automatic, for the winner only** (checked 2026-10-27, men): Div 1 winners appear in the next season's Prem (Richmond 2023/24, Brooklands MU 2024/25, Bowdon and Exeter 2025/26), Conference winners in the next season's Div 1 (Richmond 2022/23, Havant 2022/23, Lindum 2023/24, Leeds 2025/26). **Exception: a second team can't go up into its own first team's league** (checked 2026-10-28: University of Nottingham 2 won Men's/Open Conference Midlands 2023/24 and Surbiton W2 won Women's Division 1 South 2023/24, and both stayed put), so "won the league" and "promoted" differ. The Prem relegation play-off is four Prem sides, never Div 1 winners, so a Div 1 runner-up gets nothing (Loughborough missed out by one point in 2024/25).
- **No Docker? Read the seed directly.** In a cloud session with no Docker and no MySQL, the MCP server can't start. `data/seed/hockey_stats.sql.gz` is plain mysqldump text (one `INSERT ... VALUES (...),(...);` line per table), so a ~50-line Python parser can load it into SQLite in a few seconds and every query here runs unchanged except MySQL-only functions (done 2026-10-24 for the non-Prem check-in; the parser was a scratch script, not committed). Only as fresh as the last `dump.sh`: check `max(starts_at)` of `status='R'` matches before quoting "this weekend".
